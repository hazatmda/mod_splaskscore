# mod_splaskscore

Modul Joomla untuk memaparkan markah penilaian dan tarikh kemaskini terakhir dari sistem SPLaSK.

## Fungsi Utama

- Paparan markah penilaian SPLaSK melalui API rasmi.
- Tarikh kemaskini terakhir dan semakan seterusnya.
- Jam telemetry masa nyata berasaskan timezone Joomla.
- Semakan seterusnya kini memaparkan hari dan tarikh sahaja tanpa masa.

## Release v1.6.4

- `Semakan Seterusnya` kini menggunakan format seperti `Selasa • 19 Mei 2026`.
- Masa pada kad semakan seterusnya dibuang untuk mengurangkan noise visual dashboard.
- Dashboard kini menyelaraskan masa berdasarkan timezone Joomla.
